Two systems, kept deliberately apart.

Neither reads the other's output. A test in the codebase proves it.

Monitoring

A FHIR R4 stream is validated, ledgered and forecast, then drawn on an anatomical figure so each organ's signals sit together.

  • Model forecasts and carried-forward values are labelled apart
  • Every value traces back to the record it came from
  • A live synthetic stream and a retrospective replay share one pipeline

Medication Safety

A deterministic engine ranks drug candidates for an indication and draws the reasoning behind every step.

  • Safety rules are checked against label text, with the sentence that triggered them
  • A language model may explain the result but never changes it
  • No automated prescribing, and no path to an order-entry system

All seven research boundaries
  1. 01Research use onlyBuilt for methods research. Not a medical device and not cleared for care.
  2. 02Synthetic stream, not a live feedNothing connects to an EHR or a hospital. No real patient data is used.
  3. 03No diagnosisLabels shown in a case come from the source data. The system produces none of its own.
  4. 04No causal or counterfactual claimForecasts describe an observed trajectory, not what an intervention would do.
  5. 05No treatment recommendation or alertMissing, degraded and carried-forward values are data boundaries, not warnings.
  6. 06No automated prescribingNo output can reach an order-entry system.
  7. 07A forecast cannot change a drug rankingThe two systems are isolated. Neither reads the other's output.

Built on WholeBody-JEPA.

A whole-body forecasting model trained on credentialed ICU data and validated across hospitals, one forecast cell at a time. A cell that fails validation carries the last observed value forward and says so.
